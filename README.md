Programa en consola que carga productos desde un archivo de texto y permite gestionarlos usando diferentes tipos de Map.

Funcionalidades:

Cargar productos desde archivo (categoria | nombre).
Mostrar categorías, productos por categoría y colección del usuario.
Agregar productos a la colección.
Elegir implementación de mapa: HashMap, TreeMap o LinkedHashMap.

Formato del archivo .txt
Categoria | Nombre
